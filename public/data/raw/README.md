# Berkas impor mentah

Folder ini hanya untuk sumber mentah yang memang boleh disajikan kepada publik. Berkas mentah tidak dinormalisasi atau ditimpa oleh aplikasi. Berkasnya diabaikan Git secara bawaan dan harus diperiksa sebelum sengaja disertakan; hanya README ini yang masuk repository.

Pengabaian Git tidak mencegah Vite menyajikan berkas dalam `public/`. Simpan arsip internal, data pribadi, token, dan berkas admin di luar folder proyek publik, bukan di sini.

Saat ini belum ada snapshot simpul resmi yang diimpor.
